#  Pizza Sales SQL Analysis

## 📌 Project Overview

This project analyzes pizza sales data using SQL Server to understand sales performance, revenue contribution, pizza popularity, and ordering patterns.

The analysis answers a series of business questions using SQL queries and focuses on extracting meaningful insights from transactional sales data.

---

## Tools & Technologies

* SQL Server
* SQL
* GitHub

---

##  Dataset

The dataset contains four main tables:

* `orders` — Order date, time, and order information
* `order_details` — Pizza quantities and order-level details
* `pizzas` — Pizza size, price, and pizza information
* `pizza_types` — Pizza names and categories

---

##  Business Questions

The analysis answers the following questions:

1. What is the total number of orders?
2. What is the total revenue generated from pizza sales?
3. Which pizza has the highest price?
4. Which pizza size is ordered the most?
5. What are the top 5 most ordered pizza types?
6. What is the total quantity of pizzas ordered by category?
7. How are orders distributed throughout the day?
8. How many pizza types are available in each category?
9. What is the average number of pizzas ordered per day?
10. What are the top 3 pizza types based on revenue?
11. What percentage of total revenue does each pizza type contribute?
12. What is the cumulative revenue over time?
13. What are the top 3 pizza types by revenue within each category?
